# Lousa mágica

Um único arquivo (`index.html`), sem dependências, sem login e sem salvar nada.
Desenhe com o dedo, a caneta ou o mouse; o botão **Apagar** limpa a lousa.

## Publicar

1. Crie um repositório público chamado `lousa` no GitHub e envie o `index.html` para a raiz.
2. Settings → Pages → Deploy from a branch → `main` / `/ (root)` → Save.
3. Com o domínio `jhlaboratoriox.com.br` configurado no repositório `laboratoriox.github.io`,
   a lousa abre em `https://jhlaboratoriox.com.br/lousa/`.
   O repositório `lousa` não pode ter domínio customizado próprio.
